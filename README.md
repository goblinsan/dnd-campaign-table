# dnd-campaign-table

Role-aware D&D campaign table app with distinct DM/player/group views, map/surroundings context, NPC/mob visibility controls, and ambient audio support.

## Initial Scope

- Authentication and role-based access (DM, player, group/table display)
- Distinct map and encounter views per role
- Group/table mode for shared screen output
- Integration hooks for external campaign builder data (characters, mobs, locations, worlds)
